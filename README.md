# Healthcare_Data_Analytics_SQL

Healthcare data analysis project using MySQL to generate insights on patient trends, diagnoses, treatment costs, lab test activity, and doctor performance.

## Project Overview

This project uses SQL to analyze healthcare data and generate meaningful insights for hospital management. The analysis focuses on patient volume, diagnoses, follow-up requirements, treatment costs, laboratory activity, and doctor performance.

## Objectives

- Analyze total patients and doctors
- Identify yearly patient trends
- Find the most common diagnoses
- Analyze monthly follow-up rates
- Analyze monthly lab test activity
- Calculate total treatment costs
- Identify treatment records above the average cost
- Calculate average patients per doctor
- Rank doctors based on total visits

## Database Tables

The project contains five tables:

- `patient`
- `doctor`
- `visit`
- `treatment`
- `lab test`
